I-scan ang QR code para mag-install

Buksan ang camera ng iyong telepono, itutok sa QR code, at pindutin ang link na lalabas. Sinusundan nito ang opisyal na pahina ng pag-install.

Open your phone camera, point it at the QR code, and tap the link that appears. It opens the official installation page.

sbtf-application.vercel.app/install

  1. I-scan ang code

    Gamitin ang camera ng telepono at pindutin ang link na lalabas.

  2. Pindutin ang I-download

    Piliin ang “I-download para sa Android”. Payagan ang pag-install kapag tinanong ng Android.

  3. Mag-sign in

    Gumawa ng account gamit ang e-mail, o mag-sign in kung nakarehistro na. May 6-digit na code na ipapadala sa e-mail.

Filipino

  1. I-scan ang QR code gamit ang camera ng telepono.
  2. Pindutin ang “I-download para sa Android” at hintaying matapos.
  3. Buksan ang na-download na file at payagan ang “Install unknown apps”.
  4. Buksan ang SBTF, gumawa ng account, at ilagay ang 6-digit na code.

English

  1. Scan the QR code with your phone camera.
  2. Tap “Download for Android” and wait for the file to finish.
  3. Open the downloaded file and allow “Install unknown apps”.
  4. Open SBTF, create an account, and enter the 6-digit code.
